## 판정 결과 4단계

| 아이콘 | 의미 |
|--------|------|
| 🔴 | 위반 (즉시 조치 필요) |
| 🟡 | 확인 필요 |
| 🟢 | 준수 |
| ⚪ | 해당 없음 |

### A-01 사업자 유형 자동 분류

**참조 항목:** 섹션 2 (업종·근로자수·매출·자산총액)

**판정 로직:**
- 업종 대분류 + 상시 근로자 수 + 매출액 + 자산총액 5,000억 여부
- → 소상공인 / 소기업 / 중기업 / 중견기업 / 대기업 자동 분류
- ※ 업종별 기준 적용 (중기업기본법 별표1·3)

**관련 법령:** 중소기업기본법 시행령 제3조, 소상공인기본법 시행령 제3조

### A-02 CPO 지정 의무 위반

**리스크:** 과태료 1천만원 이하 (제75조④9호)

**판정 유형:** 🔴위반 / 🟢준수 / ⚪면제
