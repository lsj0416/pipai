# PIPAi 마이페이지 수정 명세서 (B군 정형화)

> **목적:** B군 11개 진단 항목을 대화 없이 마이페이지 입력만으로 판정 가능하도록 섹션별 항목 추가
> **대상:** 개발팀 | **기준일:** 2026.05.27.

---

## 1. 마이페이지 추가 항목 명세 (B군 정형화)

### 섹션 3. 개인정보 처리 현황 — 추가 항목

---

#### B-08 | 파기 절차 관리 여부

- **입력 유형:** 라디오
- **표시 조건:** 항상 표시
- **연계 진단 항목:** B-08 파기 절차 이행
- **선택지:**
  - 보유기간을 항목별로 관리하고 있음
  - 보유기간 지나면 삭제하고 있음 (기록 없음)
  - 별도 파기 절차 없음
  - 모르겠음
- **비고:** 파기 절차 여부를 1차 파악용으로 활용. 세부 파기 방법은 아래 항목으로 분리.

---

#### B-08 | 파기 방법

- **입력 유형:** 체크박스 (다중선택)
- **표시 조건:** '보유기간 관리함' 선택 시 활성화
- **연계 진단 항목:** B-08 / 안전조치 고시 제13조
- **선택지:**
  - 완전파괴 (소각·파쇄)
  - 전용 소자장비 이용
  - 삭제
  - 덮어쓰기·초기화
  - 마스킹·구멍 뚫기 (부분 파기)
  - 별도 방법 없음
- **비고:** '별도 방법 없음' 선택 시 🔴 위반 경고

---

#### B-06 | 이력서·인사서류 보관 기간

- **입력 유형:** 라디오
- **표시 조건:** 이용 목적 '채용·인사 관리' 체크 시 표시
- **연계 진단 항목:** B-06 직원 개인정보 처리
- **선택지:**
  - 채용 후 즉시 파기
  - 6개월 미만 보관 후 파기
  - 6개월~1년 보관 후 파기
  - 1년 이상 보관
  - 별도 관리 없음
- **비고:** '별도 관리 없음' → 🟡 확인 필요

---

#### B-06 | 퇴사자 개인정보 파기 시점

## 2. 리스크 대시보드 수정 사항

### 문구 수정

- **현재:** `대화에서 진단된 항목이 자동으로 정리돼요`
- **수정:** `마이페이지 + 대화에서 진단된 항목이 자동으로 정리돼요`
- **이유:** 마이페이지 기반 진단이 주 판정 수단임을 명확히

---

### 진단 항목 필터링

- **현재:** 진단 범위 외 항목 표시됨 (예: 개인정보보호위원회 공무직근로자 운영규정)
- **수정:** A군·B군 26+11개 항목만 표시되도록 필터 적용
- **이유:** 진단 범위 외 항목은 혼란 유발

---

### 마이페이지 연결 플로우

- **현재:** `기업 프로필 기반 진단 - 진단 항목 없음` 표시
- **수정:**
  - 마이페이지 미완성 시 → `마이페이지 등록 후 진단이 시작됩니다` 유도
  - 마이페이지 완성 시 → 자동 진단 실행 후 대시보드 갱신
- **이유:** 진단 결과 없음 상태에서의 사용자 이탈 방지

---

### 조치 완료 후 상태 관리

- **현재:** `완료 처리` 클릭 후 동작 불명확
- **수정:**
  - 완료 처리 클릭 → 해당 항목 🟢 전환
  - 마이페이지 재입력 시 → 재진단 자동 실행
  - 조치 완료 이력 타임스탬프 저장
- **이유:** 사용자가 개선 추이를 확인할 수 있어야 함

---

### 대화-항목 연결 매핑 설계

- **현재:** `행을 클릭하면 관련 대화로 이동해요` 기능 미구현
- **수정:**
  - 각 진단 항목에 대화 세션 ID 매핑 테이블 설계
  - 진단 항목 클릭 → 해당 대화 세션으로 이동
- **이유:** 사용자가 어떤 대화에서 해당 리스크가 도출됐는지 추적 필요

---

## 구현 참고 사항

> - 추가 항목 전체는 **조건부 표시** (섹션 내 연관 항목 선택 시 활성화) 방식으로 구현하여 불필요한 항목 노출을 최소화한다.
> - B-06·B-07은 특정 이용 목적·수집 방법 선택 시에만 표시되는 **조건부 섹션**이다.
> - 추가 항목 저장 후 → **대시보드 자동 재진단 실행** → 리스크 카운트 갱신 플로우로 연결한다.
> - 이 명세서는 개발팀 구현용이며, **UX/UI 세부 사항은 별도 협의**한다.
